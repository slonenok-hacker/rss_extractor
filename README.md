# RSS Extractor

Экстрактор ресурсов из архивов `.rss` игры **«Недетские сказки»** (студия «Сатурн-плюс», 2005).

Игра хранит все ресурсы — звуки, музыку, спрайты, фоны — в файлах `block0.rss` … `blockN.rss`.
Это бинарные архивы собственного формата, которые не распаковываются стандартными инструментами.
Данный скрипт читает формат, извлекает файлы и автоматически конвертирует аудио в воспроизводимый вид.

## Формат архива .rss

```
┌─────────────────────────────────────────────┐
│  count (uint32 LE)                           │  4 байта — количество файлов
├─────────────────────────────────────────────┤
│  Запись 0                                    │
│  ├─ name1  (null-terminated)                 │  путь файла, например Music\aerobik.WAV
│  ├─ name2  (null-terminated)                 │  дубликат пути
│  ├─ CD-паддинг (0xCD до 80 байт)             │  выравнивание
│  └─ metadata (12 байт)                       │  offset (uint32) + size (uint32) + block (uint32)
├─────────────────────────────────────────────┤
│  Запись 1                                    │
│  ...                                         │
├─────────────────────────────────────────────┤
│  Доп. таблица (count × 8 байт)              │  зарезервировано (в block12.rss — нули)
├─────────────────────────────────────────────┤
│  Данные файлов                               │  raw-данные по offset/size из записей
└─────────────────────────────────────────────┘
```

Каждая запись заголовка занимает **92 байта** (80 имени + 12 метаданных).
Между концом записей и началом данных — дополнительная таблица размером `count × 8` байт.

## Особенность аудио

Большинство WAV-файлов в архиве используют формат-тег **0x674F** («Og» — Ogg Vorbis mode 1).
Аудио упаковано в RIFF/WAV-контейнер, но внутри `data`-чанка лежит настоящий Ogg Vorbis-поток.
Стандартные плееры не распознают этот тег и отказываются воспроизводить файлы.

Скрипт определяет формат-тег и:
- **0x674F / 0x6750 / 0x6751** (Vorbis) → извлекает Ogg-поток, сохраняет как `.ogg`
- **0x0001** (PCM) → сохраняет как `.wav` с корректным RIFF-размером
- **0x0002** (ADPCM) → сохраняет как `.wav`
- **Прочие WAV** → сохраняет как `.wav` без изменений
- **Не-WAV файлы** (`.mult`, `.bmp`, `.avi`, `.old` и др.) → сохраняет raw-данные как есть

## Установка

Скрипт написан на Python 3 и не требует сторонних библиотек — только стандартная библиотека.

```bash
# Просто скачайте rss_extractor.py — этого достаточно
```

## Использование

### Извлечь один архив

```bash
python rss_extractor.py block12.rss extracted/
```

### Извлечь все .rss из папки игры

```bash
python rss_extractor.py "D:\Games\Недетские сказки" extracted/ --all
```

### Только просмотр содержимого (без записи на диск)

```bash
python rss_extractor.py block12.rss --list
```

### Dry-run — статистика без извлечения

```bash
python rss_extractor.py block12.rss extracted/ --dry-run -v
```

### Фильтрация по имени

```bash
# Только музыку
python rss_extractor.py block12.rss extracted/ --filter=Music

# Только звуки интерфейса
python rss_extractor.py block12.rss extracted/ --filter=Sound\\Inv
```

### Подробный вывод

```bash
python rss_extractor.py block12.rss extracted/ -v
```

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `input` | Путь к `.rss`-файлу или папке (с `--all`) |
| `output` | Папка для извлечённых файлов (по умолчанию `extracted/`) |
| `--all` | Обработать все `.rss`-файлы в указанной папке |
| `--list` | Вывести список файлов без извлечения |
| `--dry-run` | Показать статистику без записи на диск |
| `--filter=STR` | Извлечь только файлы, путь которых содержит STR |
| `-v` | Подробный вывод (первые 100 + последние файлы, итоговая статистика) |

## Структура извлечённых файлов

Скрипт сохраняет файлы с сохранением путей из архива:

```
extracted/
├── Music/
│   ├── aerobik.ogg
│   ├── apple1.ogg
│   └── ...
├── Sound/
│   ├── Isp/
│   │   ├── isp_0648.ogg
│   │   └── ...
│   ├── Otboy_tool/
│   │   └── ...
│   └── Scn_08/
│       └── ...
└── Speech_Process.OLD
```

## Совместимость

Скрипт тестировался на:
- **Недетские сказки** (2005) — `block12.rss`, 6930 файлов, ~180 МБ
- Python 3.8+ на Windows / Linux / macOS

Возможно работает и с другими играми студии «Сатурн-плюс», использующими тот же движок (формат `.rss` + Python 2.1 + SDL).

## Известные ограничения

- Файлы `.mult` (спрайты, анимации) извлекаются как raw-данные — для их просмотра нужен отдельный конвертер формата
- Скрипт не проверяет контрольные суммы (в архиве их нет)
- Кодировка имён — Windows-1251 (кириллица в путях не встречалась, но поддерживается)
